## Context
Illuminate has no CI covering SDM data or build_gim. Its `ci.yml` lints only `tasks.py` and `illuminate_e2e`. This PR adds a GitHub Actions workflow to graylog-sdm that runs every check from PRs 2 and 3. Illuminate's `ci.yml` (uv + `invoke`) is a useful style reference, but don't copy its jobs.

## Decisions (from interview)
- Every PR runs: structural validation, codified rules (new violations fail), TOML formatting, generated-output freshness, and Python QA (ruff, mypy, pytest).
- If the committed `generated/MadcapHtmlOutput/` is stale, the PR fails. CI does **not** auto-commit; the contributor runs `build-sdm build` and commits the result.
- Python 3.13 only.

## Steps
1. Branch `migration/04-ci`.
2. `.github/workflows/ci.yml`:
   - `on: pull_request` (branches `[main]`), `push` (branches `[main]`), `workflow_dispatch`
   - `permissions: contents: read`
   - `concurrency: ci-${{ github.ref }}` with cancel-in-progress
   - shared setup steps:
     - `actions/checkout@v4` with `fetch-depth: 0` (needed for the base ref)
     - `astral-sh/setup-uv` with caching, pinned to a version
     - `uv python install 3.13`
     - `uv sync --locked`
   - jobs:
     - **data-lint**
       - `uv run taplo fmt --check`
       - on PRs: `uv run build-sdm validate --base-ref origin/${{ github.base_ref }}`
       - on push and dispatch: `uv run build-sdm validate --base-ref HEAD~1`; on the first commit, fall back to no base
     - **generated-fresh**
       - `uv run build-sdm check-generated`
       - on failure, a step writes the fix to `$GITHUB_STEP_SUMMARY`: `uv run build-sdm build && git add generated/`
     - **python-qa**
       - `uv run ruff check`
       - `uv run ruff format --check`
       - `uv run mypy tools/build_sdm`
       - `uv run pytest`
3. Pin third-party actions to a major version, or to a SHA if org policy requires it.
4. Use stable job names, so the governance proposal (PR 5) can list them as required checks.
5. `AGENTS.md`: add a short "CI" section listing the jobs and the local command that reproduces each one.
6. Plan status: set `docs/plans/sdm-migration/04-ci.md` to `Status: done` and mark PR 4 done in the `README.md` status table.
